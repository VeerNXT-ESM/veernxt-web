# VeerNXT Visual Asset Library

## Visual Direction

**Style:** Premium editorial 3D illustration, modern Indian enterprise, subtle military precision.

**Palette:** VeerNXT green, muted gold, deep navy, ivory/white.

**Rules:**

* Consistent visual language across every asset
* Clean geometric forms
* Subtle 3D depth and soft lighting
* Premium but restrained
* No stock-photo aesthetic
* No cartoon characters
* No unnecessary people
* No baked-in text, numbers or UI
* Transparent or very light background where appropriate
* Designed specifically for small web/mobile UI
* Maintain the same lighting, materials and perspective across the entire collection

# D. ₹9 PROMOTIONAL SYSTEM

Create one **master visual language** for all low-cost unlocks so the offers feel like part of VeerNXT rather than advertisements.

### Master concept

**Military Profile → VeerNXT Analysis → Career Result**

Create variants:

1. **Unlock VeerScore — ₹9**
2. **Unlock Career Analysis — ₹9**
3. **Unlock Exam Matches — ₹9**
4. **Unlock Industry-Fit CV — ₹9**
5. **Unlock Career Map — ₹9**
6. **CV + Career Profile — ₹9**
7. **Unlock Your Next Step — ₹9**

The artwork should communicate **discovery, analysis and unlocking potential**, not a generic shopping discount.

Use the UI for the actual price and offer text. Do **not** bake ₹9 or promotional copy into the image.
